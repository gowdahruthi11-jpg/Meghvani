🌧️ Event Detection Thresholds
🌱
Monsoon Onset
Cumulative rainfall ≥ 20mm over 3 consecutive days. 30-day lockout debounce prevents repeated triggers.
≥ 20mm / 3 days
30-day lockout
⚠️
False Onset
Onset trigger followed by ≥ 7 dry days (<2.5mm/day) within 30-day lookahead window.
≥ 7 dry days lookahead
< 2.5mm/day dry ceiling
🏜️
Break Spell
≥ 5 consecutive dry days (<2.5mm/day) during active monsoon. Each break assigned a unique episode ID.
≥ 5 consecutive days
< 2.5mm/day
⛈️
Heavy Rain
IMD standard: Heavy ≥ 64.5mm/day. Very Heavy ≥ 115.5mm/day. Single-day window.
≥ 64.5mm/day (heavy)
≥ 115.5mm/day (v.heavy)
💧
Revival
≥ 15mm cumulative over 2 days after a break spell episode ends.
≥ 15mm over 2 days
📅
Horizons
Binary classification targets for future event within N calendar days, strictly after prediction date T.
7d · 14d · 21d · 30d

📋 Advisory Rule Validation Hierarchy
✅
VALIDATED
Approved by institutional authority (ICAR-CRIDA, ICAR-CICR, Dr. PDKV, Govt. Maharashtra). Only these can produce farmer-facing advisory text. Must specify: institution, publication, version, date, rule_id.
6
⏳
REVIEW_REQUIRED
Under review by agronomists / KVK. Blocked from operational farmer dispatch until localized sign-off. Intercropping posture rules are in this state.
2
❌
UNVALIDATED
Demonstration rules awaiting formal review. Never matched in advisory lookups. Vague attributions ("AI knowledge", "Internet") strictly rejected by validate_rule_source().
3
🚫
UNAVAILABLE / NO_VALIDATED_RULE
No rule for the crop + decision + language combo. advisory_text = null. action_type = null. System never fabricates advice — strict null safety enforced.
—
